# v0.1.0 Public Guardrails Baseline

Initial public hardening release for the Strands PHI Guardrails Demo.

Included:

- deterministic guardrail eval tests for RBAC, PHI-pattern checks, BAA-status gating, and audit logging;
- GitHub Actions CI for the guardrail test suite;
- public `SECURITY.md` with no-PHI reporting guidance;
- MIT license;
- explicit backlink to the Small Practice Security Kit;
- branch-normalization plan documenting `main` as canonical and `master` as legacy compatibility only.

Boundaries:

- This release is a demo and reference pattern.
- It does not provide HIPAA certification, legal advice, production authorization, breach notification decisions, or a formal security risk analysis opinion.
- Use only synthetic examples in public issues, demos, and screenshots.
