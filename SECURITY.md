# Security Policy

## Supported Scope

This repository is a public, synthetic healthcare AI guardrails demo. It should
not contain real PHI, patient identifiers, credentials, vendor secrets,
production logs, contracts, or live customer data.

## Reporting

Please report security issues privately to Noah Mills before opening a public
issue. Include the affected file or workflow, expected impact, and enough
non-sensitive detail to reproduce the concern.

## Handling Rules

- Do not include PHI, credentials, secrets, or real patient/practice data in a
  report, issue, pull request, screenshot, or test fixture.
- Use synthetic examples when describing RBAC, purpose-of-use, BAA, or PHI
  detection concerns.
- This demo does not provide legal advice, HIPAA certification, breach
  determination, or production authorization controls.
